# AI Context for EventRegistrar Admin Angular Project

## Project Overview

This is an Angular frontend application for EventRegistrar admin functionality, built with the Fuse template. The project uses Angular, Tailwind CSS, and connects to a backend API.

## Development Rules & Guidelines

### 🚀 API Communication

-   **ALWAYS use `src/app/api/api.ts`** for making calls to the backend
-   Do not create separate HTTP service files - utilize the existing API structure
-   Follow the established patterns in api.ts for new endpoints
-   Use the error handling interceptor already configured
-   **Do NOT refresh data after executing commands** - data is automatically refreshed through events from the backend (see NotificationService)

### 🎨 Styling Guidelines

-   **Use Tailwind CSS classes instead of custom CSS**
-   Avoid writing custom CSS files unless absolutely necessary
-   Leverage the existing Tailwind configuration in `tailwind.config.js`
-   Use Fuse's pre-built components when available in `src/@fuse/components/`
-   Follow the existing design system patterns

### 📁 Project Structure Guidelines

-   **Modules**: Place new features under `src/app/modules/admin/`
-   **Shared Components**: Use `src/app/shared/` for reusable components
-   **Core Services**: Place in `src/app/core/`
-   **Fuse Components**: Extend existing Fuse components from `src/@fuse/`

### 🔧 Angular Patterns

-   Follow the established routing patterns in `app.routing.ts`
-   Use resolvers for data fetching when appropriate
-   Implement proper TypeScript typing
-   Follow Angular style guide conventions

### 🌐 Internationalization

-   Use ngx-translate for all user-facing text
-   Translation texts are in the backend, do not add new translations. Create new translation keys though if needed.
-   Follow existing translation key naming patterns

### 📱 Responsive Design

-   Ensure all components work across different screen sizes
-   Use Tailwind's responsive utilities
-   Test on mobile and desktop viewports

### 🔍 Code Quality

-   Follow existing code patterns and conventions
-   Use proper component lifecycle methods
-   Implement error handling and loading states
-   Write clean, maintainable TypeScript code

## Key Files to Reference

-   `src/app/api/api.ts` - API communication patterns
-   `src/@fuse/components/` - Available UI components
-   `tailwind.config.js` - Tailwind configuration
-   `src/app/core/` - Core services and utilities
-   `src/app/shared/shared.module.ts` - Shared components and modules

## Environment Configuration

-   Development: `src/environments/environment.ts`
-   Production: `src/environments/environment.prod.ts`
-   Static Web App config: `staticwebapp.config.json`

## Notes

-   This project uses Fuse template components and services
-   Authentication is handled through Auth0 configuration
-   The project is configured for Azure Static Web App deployment
